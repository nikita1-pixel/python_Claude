AI Loan-Default Predictor

Can we predict — and *explain* — whether a new loan will default, before it's approved? An end-to-end ML model, tuned on real cost trade-offs, with an AI layer that explains every decision. Deployed live.

📌 The problem

  • A dashboard tells you what already happened. A lender needs to score a brand-new applicant — before the outcome is known.
  • Goal: predict a single loan's default probability and explain why, so the decision is trustworthy and actionable.

🔧 How I built it

  • Trained a Logistic Regression model on 1.3M real loans using 8 features (interest rate, term, DTI, income, loan amount, utilization, open accounts, credit grade).
  • Encoded the A–G credit grade into numbers, scaled features, and used a stratified 80/20 train/test split so the model is tested on data it never saw.
  • Saved the trained model and deployed it as an interactive Streamlit app.
raw loan → ML model → default-probability score → AI explains why → recommendation

📊 The key decision (this is the real analyst work)

  • At the default 0.5 cutoff: 79.9% accuracy — but that's a trap. It equals the "always predict repaid" baseline, and caught only 7% of real defaulters.
  • ROC-AUC of 0.70 showed the model had real signal — the problem was the threshold, not the model.
  • I tuned the cutoff to 0.20 based on the actual cost trade-off: a missed default (~$10k) costs far more than a wrongly rejected good customer (~$1.5k). That lifted defaulters caught from 7% to ~60%.

🤖 The AI layer

  • A probability alone isn't a decision. The model's score + the loan's details are sent to an LLM (Llama 3.3 via Groq), which writes a plain-English explanation and a recommendation.
  • Example output: "83% default probability — high DTI (69%), low income ($16.9k), 30.9% rate and riskiest grade all point to a stretched borrower. Recommendation: reject."

✅ What makes it stand out

  • It's predictive, not descriptive — it scores a new loan, not a historical average.
  • It's self-explaining — anyone, technical or not, gets the why and a recommendation.
  • It's honestly evaluated — the threshold was chosen on business cost, and its limits are documented, not hidden.
The difference this makes: it's a complete, deployed ML + AI product — from 1.3M raw loans to a live link anyone can try — built and understood end to end.
